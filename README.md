# VidGrab

Universal Video Downloader Chrome Extension.

## Features
- Smart 3-Tier Capture System
  - Tier 1: AES-128 HLS key fetching using authenticated sessions
  - Tier 2: SourceBuffer Hook for MSE capture
  - Tier 3: Accelerated Frame Capture for hard DRM
- MP4 and MP3 support
- Beautiful Glassmorphism UI
- Fast, parallel downloads

## Installation (Developer Mode)
1. Clone this repository or download as ZIP
2. Open Chrome and go to `chrome://extensions/`
3. Enable "Developer mode" in the top right
4. Click "Load unpacked" and select the extension folder
5. Pin the extension to your toolbar!
